# Maria Kovalenko Photography

Односторінковий сайт весільного фотографа з адаптивною версткою, галереєю, відгуками, FAQ та контактною формою.

## Технології

- Vite
- HTML5, CSS3, JavaScript
- API wedding-photographer

## Запуск

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Командна робота

Робота ведеться у feature-гілках. Зміни потрапляють у `main` тільки через Pull Request після перевірки та review.

Основні каталоги:

- `src/partials` — HTML-секції;
- `src/css` — стилі секцій;
- `src/js` — API та інтерактивна логіка;
- `src/img` — зображення та SVG sprite.
